LifeSync на Oracle VM
без работающего ПК

Ubuntu 24.04 ARM, Docker Compose, PostgreSQL 17, Node API/web, jobs, backup и Caddy работают на VM. Команды вводятся через браузерный Oracle Cloud Shell: подключитесь по SSH к VM и выполняйте их там. После настройки можно закрыть браузер и выключить компьютер.

Always Free — не гарантия бесплатности навсегда. Oracle проверяет аккаунт/карту, может не иметь свободной ARM-ёмкости и может забрать idle VM. Проверяйте текущие квоты и цену перед созданием. Галочка означает вашу проверку результата, а не автоматическую проверку облачного аккаунта.

Публичные настройки для подстановки

Пароли, DuckDNS-токен, Turnstile secret и API-ключи сюда не вводятся. Они не сохраняются в чек-листе или экспорте JSON.

Прогресс и перенос между браузерами

Сохраняются публичные настройки и отметки. Экспортируйте JSON перед очисткой браузера. Из старого Cloudflare/Neon v2 импортируются только подходящие публичные настройки; старые галочки не применяются к Oracle.

Все шаги отмечены.

Результат подтверждён вашими отметками. Для всего набора внешних функций нужны действующие Google/Gemini/Push credentials и их квоты. Сохраняйте копии вне VM и продолжайте проверять условия сервисов.
